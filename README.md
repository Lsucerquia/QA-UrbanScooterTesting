# Pruebas funcionales de aplicaciones web, móviles y API – Urban Scooter

Proyecto de **Quality Assurance (QA)** enfocado en la validación funcional de una aplicación de Urban Scooter en sus versiones **web, móvil y API**, de acuerdo con los requisitos establecidos.

## 🧪 ¿Qué realicé?

### Pruebas de aplicación web

* Elaboré una **lista de comprobación** para validar los requisitos funcionales de la pantalla **“Estado del pedido”**.
* Diseñé y ejecuté **casos de prueba** para validar los campos y funcionalidades de la pantalla **“Hacer pedido”**.
* Realicé pruebas positivas y negativas para verificar el comportamiento esperado de las funcionalidades.
* Identifiqué, documenté y reporté los defectos encontrados en **Jira**.

### 📱 Pruebas de aplicación móvil

* Diseñé y ejecuté casos de prueba para validar las **notificaciones** y el comportamiento de determinadas funcionalidades **sin conexión a Internet**.
* Utilicé el emulador de **Android Studio** para realizar las pruebas en la aplicación móvil.
* Utilicé **Postman** para crear repartidores y pedidos necesarios para preparar los datos de prueba.

### 🔌 Pruebas de API

* Diseñé una **lista de comprobación** para validar la API de Urban Scooter.
* Ejecuté pruebas de los endpoints mediante **Postman**.
* Validé las solicitudes, respuestas y códigos de estado HTTP para comprobar el funcionamiento esperado del backend.
* Verifiqué diferentes escenarios de prueba, incluyendo casos positivos y negativos.

## 🔍 Técnicas de prueba aplicadas

* Clases de equivalencia
* Análisis de valores límite
* Pruebas positivas y negativas
* Pruebas funcionales
* Pruebas exploratorias
* Pruebas de regresión
* Pruebas de API

## 🛠️ Herramientas utilizadas

* **Jira** – Gestión y seguimiento de defectos.
* **Postman** – Pruebas de API y preparación de datos de prueba.
* **Android Studio** – Ejecución de pruebas en dispositivo móvil mediante emulador.
* **Excel** – Diseño y ejecución de listas de comprobación y casos de prueba.

## 📚 Lo que aprendí

A través de este proyecto fortalecí mis habilidades prácticas en **Quality Assurance**, especialmente en el análisis de requisitos, diseño y ejecución de casos de prueba y listas de comprobación, identificación y documentación de defectos y validación de aplicaciones web, móviles y APIs.

También adquirí experiencia práctica utilizando herramientas como **Jira, Postman, Android Studio y Excel**, aplicando diferentes técnicas de testing para validar el comportamiento de las funcionalidades y detectar posibles defectos.

## 🎯 Resultado

El proyecto me permitió aplicar un proceso de pruebas de software de manera práctica, desde el **análisis de requisitos y diseño de pruebas**, hasta la **ejecución, identificación y reporte de defectos**, cubriendo diferentes capas de la aplicación: **web, móvil y backend mediante API**.
